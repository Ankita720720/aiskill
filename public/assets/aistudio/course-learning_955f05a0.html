Introduction to Node.js

Understand what Node.js is and why it is used.

LESSON 1

Node.js allows JavaScript to run outside the browser. It is commonly used to create fast and scalable backend applications.

What is Node.js?

Node.js is a JavaScript runtime built on Chrome's V8 JavaScript engine. It allows developers to execute JavaScript on the server.

Simple Example

console.log("Hello from Node.js"); const http = require("http"); const server = http.createServer((req, res) => { res.end("Hello World"); }); server.listen(3000);
